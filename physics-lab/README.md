# LIMINAL — NVIDIA PhysX 5.12 / GPU PBD physics lab

**Результат 26.10.2026:** отдельно от игры собраны и запущены официальные SDK PhysX с физическим ударом по PBD-частицам. **Не заявлять как установленную игровую механику IX-Ray.**

## Что здесь установлено

- `vendor/PhysX/physx/`, `vendor/PhysX/blast/`, `vendor/PhysX/flow/` — официальные исходники NVIDIA PhysX 5.12.0, Blast и Flow, git `b97365c`; Blast/Flow пока только подготовлены, не скомпилированы и не внедрены.
- `vendor/ovphysx-sdk/ovphysx/` — официальный нативный C/C++ SDK `ovphysx 0.7.0`, GPU PhysX runtime и примеры.
- `.venv/` — изолированная Python 3.12-среда: `ovphysx==0.7.0.74035321`, `ovstage`, `warp-lang`, USD-схемы и Pillow. Не глобальная установка.
- `build/` — Visual Studio 2022 Release-сборки отдельных SDK-примеров и нашего native PBD-прототипа.
- `experiments/pbd_shot.py` — **реальное** взаимодействие физического снаряда с GPU-PBD; сравнение с контрольным запуском.
- `integration/native_pbd/` — оригинальная C-программа, работающая непосредственно через официальный C API NVIDIA.
- `reports/pbd_shot_real_gpu.gif` — анимация **из фактически рассчитанных координат**, не подставные FX.
- [`reports/pbd_shot_live.webp`](reports/pbd_shot_live.webp) — та же реальная симуляция в компактном анимированном WebP, опубликована в GitHub; снимки [`impact`](reports/pbd_shot_impact_preview.png) и [`final`](reports/pbd_shot_final_preview.png).

## Первый опыт

- 420 PBD-частиц (гранулярный набор), PhysX 5.12, CUDA-устройство RTX 4090 Laptop.
- Физический снаряд: `5 кг`, стартовая скорость `13,5 м/с`; 132 шага по `1/120 сек`.
- Контроль без выстрела рассчитан отдельно с тем же первоначальным расположением.
- 286/420 частиц изменили позицию относительно контроля более чем на 1 см за 1,1 секунды.
- Снаряд получил обратный импульс. Возвращены координаты, CSV, NPZ, JSON и GIF.
- В **финальной успешной демонстрации гравитация выключена** — это чистый опыт удара по свободному гранулярному массиву, не моделирование лежащей на земле грязи.
- Первая попытка с гравитацией выявила нестабильный вертикальный отскок частиц. Её материалы сохранены отдельно в `reports/first_gravity_9_81/`. Настройку PBD-материала и контактов ещё нужно довести.

## Запуск одной командой

Из PowerShell в папке лаборатории:

```powershell
.\run_first_shot.ps1 -Show
```

Или двойным щелчком открыть `reports\pbd_shot_real_gpu.gif`.

Скрипт повторно рассчитывает две физические сцены, записывает вывод и визуализацию, затем проверяет нативное C-приложение. Он **не запускает игру и не меняет игровые DLL**.

## Проверка нативного SDK

- C++ PhysX SDK `SnippetHelloWorld_64.exe`: собран и запущен, exit 0.
- NVIDIA `ovphysx` C SDK: собственный `liminal_native_pbd_shot.exe` собран Visual Studio 2022 и прогнал 132 физических шага с загруженными 420 GPU-частицами.
- C API возвращает CUDA tensors: `device=2` = `kDLCUDA`. Журналы в `reports/native-pbd-shot-verified.log`.
- В логах нативного SDK появляется предварительное сообщение о неудачном поиске `PhysXGpu_64.dll`. Оно не прервало тест; наличие CUDA-тензоров и корректное завершение подтверждены, но диагностика загрузчика ещё требует отдельной проверки.

Для сборки standalone GPU Physics из источников в будущем понадобится CUDA Toolkit 12.8; **для этих уже работающих GPU-тестов NVIDIA предоставляет бинарный runtime, Toolkit не требуется**. Не устанавливаем глобально 3–4 ГБ без необходимости.

## Логика интеграции с IX-Ray

См. `integration/IXR-PHYSX-BRIDGE.md`. **На данный момент GPU-PBD не подключён к игровой `xrPhysics.dll`**; это полноценный изолированный симуляционный прототип плюс компилируемый нативный адаптер к C SDK. Не заменять штатный ODE бинарник и не ломать звук/управление до интеграционных измерений.

## Воспроизводимость и лицензии

Зависимости зафиксированы в `requirements-lock.txt`. Исходники NVIDIA остаются отдельно в `vendor/`; наш GitHub содержит только собственные тесты, инструкции и ссылки. Отдельные лицензии upstream соблюдать.
